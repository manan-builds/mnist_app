\# Image Classification App (CNN)



\#Description

This project is a CNN-based image classifier trained on CIFAR-10.

It allows users to upload an image and get a predicted class with confidence.



\#Dataset

CIFAR-10



\#Model

•2 Convolution layers

•ReLU + MaxPooling

•Fully connected classifier



\#Installation

```bash

pip install -r requirements.txt



Run App



python app/app.py



Example Output

&nbsp;	•Image: dog

&nbsp;	•Prediction: dog (0.92)



Results

•Test Accuracy: 83.8%
